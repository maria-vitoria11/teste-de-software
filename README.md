Atividade - Smartphone

Descrição

Este projeto foi desenvolvido em TypeScript como uma atividade prática para trabalhar com tipagem, objetos, funções e estruturas condicionais**.

O programa representa um smartphone por meio de um objeto e exibe suas principais informações. Em seguida, verifica se o preço do celular está dentro do valor máximo de R$ 4.000,00.

## Tecnologias utilizadas

- TypeScript
- Node.js

## Funcionalidades

O programa:

- Armazena informações de um smartphone;
- Exibe marca, preço, ano de fabricação, armazenamento, modelo e cor;
- Verifica se o preço do celular é menor ou igual a R$ 4.000,00;
- Informa se o usuário pode ou não comprar o celular.

## Estrutura do Smartphone

O objeto possui as seguintes propriedades:

- **Marca:** Samsung
- **Preço:** R$ 4.000,00
- **Ano de fabricação:** 2026
- **Armazenamento:** 256 GB
- **Modelo:** S26
- **Cor:** Dourado
